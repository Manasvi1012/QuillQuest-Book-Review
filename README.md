# QuillQuest-Book-Review
QuillQuest is a book rating and analysis website that provides readers and authors with useful resources like book critiques, preference lists, reading history, and book reviews that shapes the journey of both authors and readers. 
This website is made entirely manually with guidance from Youtube lectures, google searches and html learning resources. No element of this website is suggested ,planned or developed by using Artificial Intelligence. 

{This website is made only using frontend elements and uses no parts of backend or database.}
